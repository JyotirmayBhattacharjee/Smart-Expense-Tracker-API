# AI_NOTES.md

## AI Tools Used

I used ChatGPT as a development assistant during this assignment.

## What AI Helped With

- Discussing the overall project structure.
- Reviewing REST API design and Spring Boot implementation.
- Generating examples for controller, service, and frontend code.
- Explaining Spring Boot concepts and resolving implementation issues.
- Reviewing documentation and improving project organization.

## What I Implemented and Verified

I personally:

- Created and configured the Spring Boot project.
- Implemented and integrated the REST API endpoints.
- Connected the frontend with the backend APIs.
- Implemented input validation and exception handling.
- Tested each API manually using Swagger and the web interface.
- Fixed compilation and configuration issues during development.
- Wrote and executed JUnit test cases.
- Verified that the application builds and runs successfully.

## Changes Made After AI Suggestions

The generated suggestions were reviewed and modified during implementation. Several changes were made while integrating the components, fixing errors, improving the frontend, and ensuring the project met the assignment requirements.

## Debugging Assistance

During development I encountered a few issues, including static resource loading, project configuration, GitHub push conflicts, and JUnit test setup. I used ChatGPT to help identify the root cause of these errors, understand why they occurred, and verify the appropriate fixes before applying them.


## AI Suggestions Not Used

A database-based implementation was suggested during development. Since the assignment explicitly allowed in-memory storage, I chose to keep the application lightweight by using in-memory storage instead.
